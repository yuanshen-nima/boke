# 论文知识库 · 平台限制与已知局限

## 明确不能做的

1. **无法实时读取 ChatGPT Projects。** OpenAI 目前没有公开的「项目会话列表/内容」API。
   本系统不实现任何私有接口抓取、浏览器 Cookie 提取、无头浏览器无人值守抓取或验证码绕过。
   `SourceAdapter`（`paper_sync/sources.py`）为未来官方接口预留，出现受支持的 API 时实现接入即可。
2. **导出数据不含图片本体。** 官方导出中的多模态消息只有资源指针，系统会生成「缺失资源记录」写入草稿，需人工补图。
3. **项目归属可能无法自动判断。** 部分导出没有 project_id 字段；此时依赖对话 ID 白名单或人工确认，系统绝不凭标题关键词猜测归属。
4. **自定义域名不保证大陆访问。** Vercel/Cloudflare 无大陆节点，自定义域名只是改善。

## 隐私风险与缓解

| 风险 | 缓解 |
|---|---|
| 原始对话含 API 密钥 | 发送给 LLM 前强制正则脱敏；成稿发布前再过确定性扫描，命中即拒绝 |
| 未公开的科研想法/实验数字被自动公开 | 默认 draft；发布需明确 approve；LLM 复审语义级风险；可用 blocked_projects 整体排除科研项目 |
| AI 幻觉编造数据 | schema 强制；公式/实验数字一律标记 verified=false；离线模式只做确定性提取 |
| 归纳质量依赖模型 | 所有 AI 内容带「未核实」标记，人工核验后可提升 |

## 其他已知限制

- DeepSeek 输出不合 schema 时重试 2 次，仍失败则该来源记为 error，需人工处理后重跑
- Neon 免费版空闲休眠，评论接口首次请求略慢（与论文系统无关，同属博客既有链路）
- 分卷截断的导出只能恢复已完整闭合的对象，残缺部分进缺失记录
